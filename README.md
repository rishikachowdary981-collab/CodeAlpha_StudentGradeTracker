# Student Grade Tracker

## 📌 Project Overview

The **Student Grade Tracker** is a Java console-based application used to manage and analyze student grades. The program allows the user to enter student names and their grades, calculate the average, highest, and lowest grades, and display a summary report.

## 🎯 Objectives

* Store student names and grades.
* Calculate the average grade.
* Find the highest grade.
* Find the lowest grade.
* Display a summary of all students and their grades.
* Provide a simple console-based interface.

## 🛠️ Technologies Used

* **Programming Language:** Java
* **IDE:** Visual Studio Code
* **JDK:** Java Development Kit
* **Data Storage:** Arrays / ArrayList
* **Interface:** Console

## ✨ Features

1. Enter the number of students.
2. Enter each student's name.
3. Enter each student's grade.
4. Calculate the average grade.
5. Identify the highest grade.
6. Identify the lowest grade.
7. Display a complete student grade summary.

## ▶️ How to Run the Project

### Step 1: Open the project

Open the `StudentGradeTracker` folder in **Visual Studio Code**.

### Step 2: Open the Terminal

In VS Code, select:

```text
Terminal → New Terminal
```

### Step 3: Compile the Java program

Run:

```bash
javac StudentGradeTracker.java
```

### Step 4: Run the program

Run:

```bash
java StudentGradeTracker
```

## 📊 Calculations

### Average

```text
Average = Sum of all grades / Number of students
```

### Highest Grade

The program compares all grades and identifies the maximum value.

### Lowest Grade

The program compares all grades and identifies the minimum value.
